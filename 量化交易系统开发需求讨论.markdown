## 1. 系统总览

### 1.1 核心愿景

**用系统替代主观判断，用数据替代情绪驱动。**

系统不是一个"自动赚钱机器"，而是一个"永远不会自我欺骗的交易员外骨骼"：
- **盘前**：AI扫描全市场 → 生成观察池与作战计划
- **盘中**：实时行情 + 指标信号 → 辅助决策（人做最终判断）
- **盘后**：自动复盘 → 归因分析 → 策略进化 → 次日计划

### 1.2 六大核心模块

| 编号 | 模块 | 核心职责 |
|------|------|---------|
| M1 | 📊 **行情引擎** | K线/分时/资金流/板块轮动数据采集与缓存 |
| M2 | 🎨 **可视化前端** | PC + H5 响应式看盘界面（ECharts + lightweight-charts） |
| M3 | 📈 **CZSC 缠论引擎** | 缠论分析、技术指标、信号生成、多周期联立 |
| M4 | 🤖 **AI 智能体系统** | 投研/短线/波段三个智能体 + 用户自定义 |
| M5 | 📝 **复盘引擎** | 每日自动复盘 + 选股池生成 + 策略归因 |
| M6 | 💰 **交易模块** | 模拟交易（AI自主） + 实盘交易导入（用户手动） |

### 2.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **缓存优先** | 历史数据一旦固化绝不重复请求，只有当日实时数据需要拉取 |
| **异步驱动** | 数据采集/复盘/AI调用全部异步（Celery + Redis），不阻塞API |
| **模块化** | 每个功能独立Router + Service，AI/数据源可插拔替换 |
| **用户配置** | 所有AI参数（API/Key/模型/提示词）用户可自行配置 |
| **自我进化** | 复盘结果反馈到策略参数，形成闭环优化 |

## 3. 技术栈与项目结构

### 3.1 技术栈总览

| 层级 | 技术选型 |
|------|---------|
| **前端框架** | Vue 3.4+ (Composition API) |
| **UI 组件库** | Element Plus (PC) / Vant (H5) |
| **K线图表** | lightweight-charts (TradingView) + ECharts 5 |
| **状态管理** | Pinia |
| **HTTP/WS** | Axios + Socket.IO Client |
| **构建工具** | Vite 5 |
| **响应式** | PostCSS + Flexible 适配（rem/vw） |
| **后端框架** | Python 3.12+ / FastAPI 0.115+ |
| **异步任务** | Celery 5 + Redis 7 |
| **定时调度** | Celery Beat |
| **WebSocket** | fastapi-socketio / uvicorn |
| **ORM** | SQLAlchemy 2.0 (async) |
| **数据库** | PostgreSQL 16 + TimescaleDB 2.14 |
| **缓存** | Redis 7 |
| **数据源** | akshare 1.14+ / 腾讯财经API / Tushare Pro |
| **缠论引擎** | CZSC 0.9+ (github.com/waditu/czsc) |
| **缠论Skills** | czsc_skills (github.com/zengbin93/czsc_skills) |
| **LLM调用** | openai SDK / anthropic SDK（兼容格式） |
| **容器化** | Docker + Docker Compose |
| **部署** | Nginx + Gunicorn + Uvicorn Workers |

## 4. 数据库设计

### 4.1 TimescaleDB 超表设计（时序行情数据）

```sql
-- ============================================================
-- 启用 TimescaleDB 扩展
-- ============================================================
CREATE EXTENSION IF NOT EXISTS timescaledb;

-- ============================================================
-- K线数据（超表）- 按时间自动分区
-- ============================================================
CREATE TABLE klines (
    symbol      VARCHAR(20)  NOT NULL,   -- 代码 e.g. 'SH600519'
    period      VARCHAR(10)  NOT NULL,   -- 周期: 1m/5m/15m/30m/60m/day/week
    timestamp   TIMESTAMPTZ  NOT NULL,   -- K线时间戳
    open        DECIMAL(12,4),
    high        DECIMAL(12,4),
    low         DECIMAL(12,4),
    close       DECIMAL(12,4),
    volume      BIGINT,
    amount      DECIMAL(20,2),          -- 成交额
    turnover    DECIMAL(10,4),          -- 换手率
    created_at  TIMESTAMPTZ DEFAULT NOW(),
    PRIMARY KEY (symbol, period, timestamp)
);

-- 转为超表，按天分区
SELECT create_hypertable('klines', 'timestamp', chunk_time_interval => INTERVAL '7 days');

-- 索引
CREATE INDEX idx_klines_symbol_period ON klines(symbol, period, timestamp DESC);

-- ============================================================
-- 分时数据（超表）- 盘中实时
-- ============================================================
CREATE TABLE tick_data (
    symbol      VARCHAR(20)  NOT NULL,
    timestamp   TIMESTAMPTZ  NOT NULL,
    price       DECIMAL(12,4),
    volume      BIGINT,
    amount      DECIMAL(20,2),
    PRIMARY KEY (symbol, timestamp)
);

SELECT create_hypertable('tick_data', 'timestamp', chunk_time_interval => INTERVAL '1 day');

-- ============================================================
-- 资金流数据（超表）
-- ============================================================
CREATE TABLE money_flow (
    symbol      VARCHAR(20)  NOT NULL,
    date        DATE         NOT NULL,
    timestamp   TIMESTAMPTZ  NOT NULL,
    main_net    DECIMAL(20,2),   -- 主力净流入
    retail_net  DECIMAL(20,2),   -- 散户净流入
    big_net     DECIMAL(20,2),   -- 大单净流入
    mid_net     DECIMAL(20,2),   -- 中单
    small_net   DECIMAL(20,2),   -- 小单
    PRIMARY KEY (symbol, timestamp)
);

SELECT create_hypertable('money_flow', 'timestamp', chunk_time_interval => INTERVAL '7 days');

-- ============================================================
-- 板块资金流（超表）
-- ============================================================
CREATE TABLE sector_money_flow (
    sector_code VARCHAR(20)  NOT NULL,
    date        DATE         NOT NULL,
    timestamp   TIMESTAMPTZ  NOT NULL,
    net_inflow  DECIMAL(20,2),   -- 净流入
    outflow     DECIMAL(20,2),   -- 流出
    total_amount DECIMAL(20,2),  -- 总成交额
    leader_symbol VARCHAR(20),    -- 领涨股
    PRIMARY KEY (sector_code, timestamp)
);

SELECT create_hypertable('sector_money_flow', 'timestamp', chunk_time_interval => INTERVAL '7 days');

-- ============================================================
-- 技术指标快照（超表）- CZSC计算结果缓存
-- ============================================================
CREATE TABLE indicator_snapshot (
    symbol      VARCHAR(20)  NOT NULL,
    period      VARCHAR(10)  NOT NULL,
    indicator   VARCHAR(50)  NOT NULL,   -- MA20/RSI/MACD/CZSC_bi等
    timestamp   TIMESTAMPTZ  NOT NULL,
    value       JSONB,                   -- 指标值（支持复杂结构）
    PRIMARY KEY (symbol, period, indicator, timestamp)
);

SELECT create_hypertable('indicator_snapshot', 'timestamp', chunk_time_interval => INTERVAL '7 days');

-- ============================================================
-- CZSC 缠论分析结果缓存
-- ============================================================
CREATE TABLE czsc_analysis (
    symbol      VARCHAR(20)  NOT NULL,
    period      VARCHAR(10)  NOT NULL,
    date        DATE         NOT NULL,
    fx_list     JSONB,       -- 分型列表
    bi_list     JSONB,       -- 笔列表
    xd_list     JSONB,       -- 线段列表
    zs_list     JSONB,       -- 中枢列表
    signals     JSONB,       -- 信号字典
    created_at  TIMESTAMPTZ DEFAULT NOW(),
    PRIMARY KEY (symbol, period, date)
);
```

## 5. 数据源与缓存策略

### 5.1 数据源路由架构

```
┌─────────────────────────────────────────────────────┐
│              DataSourceManager (核心)                │
│                                                     │
│  调用方 ──→ get_klines(symbol, period, start, end) │
│                                                     │
│  ① 检查本地缓存（PostgreSQL/TimescaleDB）            │
│     ├─ 命中 && 数据完整 && 非当日 → 直接返回        │
│     ├─ 命中 && 数据不完整 → 计算缺失区间 → ②       │
│     └─ 未命中 → ②                                   │
│                                                     │
│  ② 调用主源 (akshare)                               │
│     ├─ 成功 → 写入缓存 → 返回                      │
│     └─ 失败/超时(5s) → ③                           │
│                                                     │
│  ③ 调用备源 (腾讯财经)                              │
│     ├─ 成功 → 写入缓存 → 返回                      │
│     └─ 失败 → ④                                    │
│                                                     │
│  ④ 返回缓存中已有数据（降级）                       │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 5.2 缓存规则

| 数据类型 | 缓存策略 | 更新频率 | 过期判断 |
|---------|---------|---------|---------|
| **日K线（历史）** | 永久缓存 | 每日收盘后更新 | `last_date < 昨日` 则需补 |
| **分钟K线** | 保留30天 | 盘中实时写入 | 自动过期 |
| **当日实时数据** | Redis (TTL 60s) | 盘中轮询 | 60秒过期 |
| **财务数据** | 永久缓存 | 季报/年报发布后 | `report_date` 是否有更新 |
| **龙虎榜** | 永久缓存 | 每日收盘后 | `last_date < 昨日` |
| **板块资金流** | Redis (TTL 300s) | 盘中5分钟 | 5分钟过期 |
| **新闻/公告** | Redis (TTL 600s) | 定时轮询 | 10分钟过期 |
| **CZSC分析结果** | 永久缓存 | 每日收盘后 | `date < 昨日` 则重算 |
| **自选股实时行情** | Redis (TTL 3s) | WebSocket推送 | 3秒刷新 |

# backend/app/core/datasource/manager.py
import asyncio
from sqlalchemy.ext.asyncio import AsyncSession
from .base import DataSourceBase
from .akshare_source import AkshareSource
from .tencent_source import TencentSource

class DataSourceManager:
    """数据源管理器 - 主备切换 + 缓存"""
    
    def __init__(self, db: AsyncSession, redis_client):
        self.db = db
        self.redis = redis_client
        self.primary: DataSourceBase = AkshareSource()
        self.backup: DataSourceBase = TencentSource()
        self.timeout = 5.0  # 主源超时切换
    
    async def get_klines(self, symbol: str, period: str, start=None, end=None) -> list[dict]:
        """核心方法：带缓存的多源获取"""
        
        # ① 检查数据库缓存
        cached = await self._load_from_db(symbol, period, start, end)
        cache_info = await self._get_cache_info("kline", symbol, period)
        
        today = date.today()
        
        # 判断是否需要更新
        if cache_info and cache_info['last_date'] >= (today - timedelta(days=1)):
            # 缓存已是最新（昨日前数据不会变）
            if period == 'day' and cache_info['last_date'] >= today:
                return cached  # 当日数据也有了，直接返回
        
        # ② 计算缺失区间
        missing_start = (cache_info['last_date'] + timedelta(days=1)) if cache_info else start
        
        # ③ 尝试主源
        try:
            new_data = await asyncio.wait_for(
                self.primary.get_klines(symbol, period, missing_start, end),
                timeout=self.timeout
            )
        except (asyncio.TimeoutError, Exception) as e:
            logger.warning(f"Primary source failed for {symbol}: {e}")
            # ④ 尝试备源
            try:
                new_data = await asyncio.wait_for(
                    self.backup.get_klines(symbol, period, missing_start, end),
                    timeout=self.timeout
                )
            except Exception as e2:
                logger.error(f"Backup source also failed: {e2}")
                new_data = []
        
        # ⑤ 写入缓存
        if new_data:
            await self._save_to_db(symbol, period, new_data)
            await self._update_cache_info("kline", symbol, period, end or today)
        
        # ⑥ 合并返回
        return cached + new_data
    
    async def get_realtime_batch(self, symbols: list[str]) -> dict[str, dict]:
        """批量获取实时行情（盘中用）"""
        # 先查Redis缓存
        cached = await self.redis.mget([f"realtime:{s}" for s in symbols])
        
        # 过滤出需要更新的
        need_update = [s for i, s in enumerate(symbols) if not cached[i]]
        
        if need_update:
            try:
                fresh = await asyncio.wait_for(
                    self.primary.get_realtime_batch(need_update),
                    timeout=self.timeout
                )
            except:
                fresh = await self.backup.get_realtime_batch(need_update)
            
            # 写入Redis (TTL 3s)
            for s, data in zip(need_update, fresh):
                await self.redis.setex(f"realtime:{s}", 3, json.dumps(data))
        
        # 组装返回
        return {s: json.loads(cached[i]) if cached[i] else fresh[i] for i, s in enumerate(symbols)}

# backend/app/core/czsc_engine/analyzer.py
import czsc
from czsc import CZSC, signals
from czsc.traders import CzscTrader
from sqlalchemy.ext.asyncio import AsyncSession
from datetime import datetime
import json

class CZSCAnalyzer:
    """CZSC缠论分析器封装"""
    
    def __init__(self, db: AsyncSession, signals_config: str = None):
        self.db = db
        self.signals_config = signals_config or "czsc_config/signals_config.yaml"
    
    async def analyze(
        self, 
        symbol: str, 
        period: str = "day",
        include_intraday: bool = False
    ) -> dict:
        """
        对单只股票进行完整缠论分析
        
        返回:
        {
            "fx_list": [...],      # 分型
            "bi_list": [...],      # 笔
            "xd_list": [...],      # 线段
            "zs_list": [...],      # 中枢
            "signals": {...},      # 信号字典
            "current_state": {...} # 当前状态
        }
        """
        
        # ① 从数据库加载K线（已缓存）
        klines = await self._load_klines(symbol, period)
        
        if not klines or len(klines) < 100:
            raise ValueError(f"Insufficient kline data for {symbol}: {len(klines)} bars")
        
        # ② 构建CZSC对象
        bars = [czsc.RawBar(
            symbol=k['symbol'],
            dt=k['timestamp'],
            id=i,
            freq=period,
            open=k['open'],
            close=k['close'],
            high=k['high'],
            low=k['low'],
            vol=k['volume'],
            amount=k.get('amount', 0)
        ) for i, k in enumerate(klines)]
        
        # ③ 运行缠论分析
        c = CZSC(bars, max_bi_num=50)
        
        # ④ 提取结构
        result = {
            "symbol": symbol,
            "period": period,
            "fx_list": [self._fx_to_dict(fx) for fx in c.fx_list],
            "bi_list": [self._bi_to_dict(bi) for bi in c.bi_list],
            "xd_list": [self._xd_to_dict(xd) for xd in c.xd_list] if c.xd_list else [],
            "zs_list": [self._zs_to_dict(zs) for zs in c.zs_list] if hasattr(c, 'zs_list') else [],
            "signals": dict(c.signals) if hasattr(c, 'signals') else {},
            "current_state": self._get_current_state(c),
            "analyzed_at": datetime.now().isoformat()
        }
        
        # ⑤ 缓存结果
        await self._cache_result(symbol, period, result)
        
        return result
    
    def _get_current_state(self, c: CZSC) -> dict:
        """提取当前市场状态"""
        last_bi = c.bi_list[-1] if c.bi_list else None
        last_fx = c.fx_list[-1] if c.fx_list else None
        
        return {
            "trend": self._judge_trend(c),           # 上涨/下跌/中枢震荡
            "last_bi_direction": last_bi.direction if last_bi else None,
            "last_bi_start": last_bi.fx_a.dt if last_bi else None,
            "last_bi_end": last_bi.fx_b.dt if last_bi else None,
            "in_central": self._is_in_central(c),     # 是否在中枢内
            "central_high": self._get_central_high(c),
            "central_low": self._get_central_low(c),
        }
    
    @staticmethod
    def _judge_trend(c: CZSC) -> str:
        """判断趋势：基于最后3笔的方向"""
        if len(c.bi_list) < 3:
            return "unknown"
        
        last_3 = [bi.direction for bi in c.bi_list[-3:]]
        
        if last_3 == ['up', 'down', 'up']:
            # 检查是否创新高
            if c.bi_list[-1].fx_b.high > c.bi_list[-3].fx_b.high:
                return "uptrend"
        elif last_3 == ['down', 'up', 'down']:
            if c.bi_list[-1].fx_b.low < c.bi_list[-3].fx_b.low:
                return "downtrend"
        
        return "consolidation"
    
    async def multi_period_analysis(self, symbol: str) -> dict:
        """
        多周期联立分析
        周线定方向 → 日线定结构 → 60分钟找买卖点
        """
        result = {}
        
        for period in ["week", "day", "60min"]:
            try:
                analysis = await self.analyze(symbol, period)
                result[period] = analysis
            except Exception as e:
                logger.warning(f"Multi-period {period} failed for {symbol}: {e}")
                result[period] = None
        
        # 联立判断
        result["synthesis"] = self._synthesize(result)
        
        return result
    
    def _synthesize(self, multi: dict) -> dict:
        """多周期联立结论"""
        week = multi.get("week", {})
        day = multi.get("day", {})
        
        week_trend = week.get("current_state", {}).get("trend") if week else None
        day_trend = day.get("current_state", {}).get("trend") if day else None
        
        # 周线向上 + 日线回调 = 买点区域
        if week_trend == "uptrend" and day_trend == "consolidation":
            signal = "buy_zone"
        elif week_trend == "uptrend" and day_trend == "downtrend":
            signal = "watch_for_reversal"
        elif week_trend == "downtrend":
            signal = "avoid"
        else:
            signal = "neutral"
        
        return {
            "week_trend": week_trend,
            "day_trend": day_trend,
            "signal": signal,
            "confidence": self._calc_confidence(multi)
        }

            {
                "time": bar['timestamp'].strftime("%Y-%m-%d"),
                "open": bar['open'],
                "high": bar['high'],
                "low": bar['low'],
                "close": bar['close']
            }
            for bar in analysis.get('klines', [])
        ]
        
        # 信号标记（买卖点）
        markers = []
        for signal_name, signal_value in analysis['signals'].items():
            if 'buy' in signal_value.lower():
                markers.append({
                    "time": signal_value.get('bar_dt', ''),
                    "position": "belowBar",
                    "shape": "arrowUp",
                    "color": "#26a69a",
                    "text": signal_name
                })
            elif 'sell' in signal_value.lower():
                markers.append({
                    "time": signal_value.get('bar_dt', ''),
                    "position": "aboveBar",
                    "shape": "arrowDown",
                    "color": "#ef5350",
                    "text": signal_name
                })
        
        # 中枢区域（矩形叠加层）
        zs_regions = [
            {
                "from": zs['start_date'],
                "to": zs['end_date'],
                "high": zs['high'],
                "low": zs['low']
            }
            for zs in analysis.get('zs_list', [])
        ]
        
        # 分型标记
        fx_markers = [
            {
                "time": fx['dt'].strftime("%Y-%m-%d"),
                "position": "belowBar" if fx['mark'] == 'd' else "aboveBar",
                "shape": "circle",
                "color": "#ff9800" if fx['mark'] == 'g' else "#9c27b0",
                "size": 8
            }
            for fx in analysis.get('fx_list', [])[-30:]  # 最近30个分型
        ]
        
        return {
            "symbol": symbol,
            "period": period,
            "kline": kline_data,
            "markers": markers + fx_markers,
            "zs_regions": zs_regions,
            "signals": analysis['signals'],
            "current_state": analysis['current_state']
        }
    
    def export_html_report(self, symbol: str, output_dir: str = "data/reports") -> str:
        """使用CZSC内置函数导出交互式HTML报告"""
        # 参考：plot_czsc_signals 用法
        # https://s0cqcxuy3p.feishu.cn/wiki/ULxhwFyVkiavqhkZ2Xkc0N3fnYc
        
        output_path = Path(output_dir) / f"{symbol}_czsc.html"
        
        # 调用CZSC可视化
        # plot_czsc_signals(
        #     c=czsc_obj,
        #     signals_config=self.signals_config,
        #     output=output_path
        # )
        
        return str(output_path)

  const isMobile = ref(false)
  const isTablet = ref(false)

    const w = window.innerWidth
    isMobile.value = w < 768

  }
  
  onMounted(() => {
    check()

  })

}

# backend/app/tasks/post_market.py
from celery import current_task
from datetime import date, timedelta

@celery_app.task(bind=True, max_retries=3)
async def run_replay(self, replay_date: str = None):
    """
    每日复盘主流程（17:30执行）
    
    步骤:
    1. 数据固化（当日K线写入DB）
    2. 板块资金流分析
    3. 涨停梯队分析
    4. 个股形态批量扫描
    5. CZSC缠论批量分析
    6. 三智能体独立复盘
    7. 生成次日选股池
    8. 模拟交易AI执行
    9. 组装复盘报告
    10. 推送前端
    """
    
    target_date = date.fromisoformat(replay_date) if replay_date else date.today()
    logger.info(f"=== 开始复盘 {target_date} ===")
    
    try:
        # ── Step 1: 数据固化 ──────────────────────────
        await self._solidify_daily_data(target_date)
        
        # ── Step 2: 板块资金流 ────────────────────────
        sector_flow = await SectorAnalyzer().analyze(target_date)
        
        # ── Step 3: 涨停梯队 ──────────────────────────
        limit_analysis = await LimitAnalyzer().analyze(target_date)
        
        # ── Step 4: 个股形态扫描 ──────────────────────
        scanner = StockScanner()
        form_results = await scanner.scan_all(
            date=target_date,
            strategies=["short_term", "swing", "research"]
        )
        
        # ── Step 5: CZSC缠论批量分析（自选股 + 涨停股）──
        czsc_engine = CZSCAnalyzer(db)
        targets = await get_scan_targets(target_date)  # 自选股 + 涨停股 + 板块龙头
        czsc_results = {}
        for symbol in targets:
            try:
                czsc_results[symbol] = await czsc_engine.analyze(symbol, "day")
            except Exception as e:
                logger.warning(f"CZSC failed: {symbol} - {e}")
        
        # ── Step 6: 三智能体独立复盘 ──────────────────
        agent_executor = AgentExecutor()
        
        # A. 投研智能体
        research_review = await agent_executor.run(
            agent_type="research",
            task="daily_replay",
            data={
                "date": target_date,
                "sector_flow": sector_flow,
                "financial_data": await get_financial_snapshot(target_date),
            }
        )
        
        # B. 短线大师
        short_term_review = await agent_executor.run(
            agent_type="short_term",
            task="daily_replay",
            data={
                "date": target_date,
                "limit_analysis": limit_analysis,
                "form_results": form_results,
                "czsc_results": czsc_results,
            }
        )
        
        # C. 波段助手
        swing_review = await agent_executor.run(
            agent_type="swing",
            task="daily_replay",
            data={
                "date": target_date,
                "sector_flow": sector_flow,
                "czsc_multi_period": await get_multi_period_results(targets),
            }
        )
        
        # ── Step 7: 生成次日选股池 ────────────────────
        stock_pool = await generate_stock_pool(
            sector_flow=sector_flow,
            limit_analysis=limit_analysis,
            form_results=form_results,
            czsc_results=czsc_results,
            agent_reviews=[research_review, short_term_review, swing_review]
        )
        
        # ── Step 8: 模拟交易AI执行 ────────────────────
        await run_simulation_trading(target_date, stock_pool)
        
        # ── Step 9: 组装复盘报告 ──────────────────────
        report = ReplayReport(
            date=target_date,
            market_summary=await get_market_summary(target_date),
            sector_flow=sector_flow,
            limit_analysis=limit_analysis,
            stock_pool=stock_pool,
            agent_reviews={
                "research": research_review,
                "short_term": short_term_review,
                "swing": swing_review,
            }
        )
        
        report_id = await save_replay_report(report)
        
        # ── Step 10: 推送前端 ─────────────────────────
        await push_to_frontend(report_id, report)
        
        logger.info(f"=== 复盘完成 {target_date} ===")
        return {"status": "success", "report_id": report_id}
        
    except Exception as e:
        logger.error(f"Replay failed: {e}")
        # 重试逻辑
        raise self.retry(exc=e, countdown=60 * (self.request.retries + 1))


async def _solidify_daily_data(self, target_date: date):
    """固化当日数据 - 从缓存/实时源写入永久存储"""
    
    # 当日K线已经通过盘中实时写入
    # 这里做数据完整性校验 + 标记
    
    symbols = await get_all_traded_symbols(target_date)
    
    for symbol in symbols:
        # 校验最后一根日K是否存在
        last_k = await db.fetch_one(
            "SELECT timestamp FROM klines WHERE symbol=:s AND period='day' ORDER BY timestamp DESC LIMIT 1",
            {"s": symbol}
        )
        
        if not last_k or last_k['timestamp'].date() < target_date:
            # 缺失，补拉
            klines = await datasource.get_klines(symbol, "day", target_date, target_date)
            if klines:
                await save_klines(symbol, "day", klines)
    
    logger.info(f"Solidified {len(symbols)} symbols for {target_date}")

```python
# backend/app/core/agent/llm_client.py
import httpx
import json
from typing import Optional

class LLMClient:
    """
    统一LLM调用接口 - 兼容OpenAI格式
    支持: OpenAI / DeepSeek / Anthropic / 通义 / 智谱 / 本地Ollama
    """
    
    def __init__(
        self,
        api_base: str = "https://api.deepseek.com/v1",
        api_key: str = "",
        model: str = "deepseek-chat",
        temperature: float = 0.3,
        max_tokens: int = 4000,
        timeout: int = 60,
    ):
        self.api_base = api_base.rstrip('/')
        self.api_key = api_key
        self.model = model
        self.temperature = temperature
        self.max_tokens = max_tokens
        self.timeout = timeout
    
    async def complete(
        self,
        prompt: str,
        system_prompt: str = "",
        response_format: str = "text",  # text / json
    ) -> str:
        """统一文本补全接口"""
        
        messages = []
        if system_prompt:
            messages.append({"role": "system", "content": system_prompt})
        messages.append({"role": "user", "content": prompt})
        
        payload = {
            "model": self.model,
            "messages": messages,
            "temperature": self.temperature,
            "max_tokens": self.max_tokens,
        }
        
        if response_format == "json":
            payload["response_format"] = {"type": "json_object"}
        
        async with httpx.AsyncClient(timeout=self.timeout) as client:
            resp = await client.post(
                f"{self.api_base}/chat/completions",
                headers={
                    "Authorization": f"Bearer {self.api_key}",
                    "Content-Type": "application/json"
                },
                json=payload
            )
            
            if resp.status_code != 200:
                raise LLMError(f"API error {resp.status_code}: {resp.text}")
            
            data = resp.json()
            
            return data['choices'][0]['message']['content']
    
    async def complete_json(self, prompt: str, system_prompt: str = "") -> dict:
        """直接返回解析后的JSON"""
        raw = await self.complete(prompt, system_prompt, response_format="json")
        
        try:
            return json.loads(raw)
        except json.JSONDecodeError:
            # 尝试提取JSON块
            import re
            match = re.search(r'```json\s*(.*?)\s*```', raw, re.DOTALL)
            if match:
                return json.loads(match.group(1))
            raise
```

# backend/app/core/simulation/engine.py

class SimulationEngine:
    """模拟交易引擎"""
    
    def __init__(self, account_id: int, db: AsyncSession):

    async def load_account(self):
        """加载账户配置"""
        self.account = await get_simulation_account(self.db, self.account_id)
        
        # 加载关联的AI智能体
        agent_config = await get_agent_config(self.db, self.account.agent_config_id)
        self.agent = create_agent(agent_config)
    
    async def daily_trade(self, trade_date: date):
        """
        每日交易主循环
        """
        
        await self.load_account()
        
        # ── ① 盘前准备 ──────────────────────────────
        plan = await self._pre_market_plan(trade_date)
        
        # ── ② 上午盘执行 ────────────────────────────
        morning_trades = await self._execute_morning(plan)
        
        # ── ③ 下午盘执行 ────────────────────────────
        afternoon_trades = await self._execute_afternoon()
        
        # ── ④ 收盘结算 ──────────────────────────────
        await self._settle(trade_date, morning_trades + afternoon_trades)
        
        # ── ⑤ AI复盘 ────────────────────────────────
        await self._ai_review(trade_date)
    
    async def _pre_market_plan(self, trade_date: date) -> dict:
        """盘前计划 - AI基于复盘报告生成交易计划"""
        
        # 获取昨日复盘报告中的选股池
        replay = await get_latest_replay(self.db)
        stock_pool = replay.stock_pool if replay else []
        
        # 获取当前持仓
        positions = await self.portfolio.get_positions()
        
        # 构建上下文
        context = AgentContext(
            date=trade_date.isoformat(),
            market_data={
                "stock_pool": stock_pool,
                "positions": [p.dict() for p in positions],
            },
            user_rules=self.account.rules,
        )
        
        # AI生成交易计划
        # 这里调用智能体的 select_pool / analyze 能力
        prompt = f"""
        # 模拟交易 - 盘前计划
        
        你是模拟交易AI，基于以下信息制定今日交易计划。
        
        ## 账户信息
        - 当前资金: {self.account.current_capital}
        - 当前持仓: {json.dumps([p.dict() for p in positions], ensure_ascii=False)}
        
        ## 交易规则
        {json.dumps(self.account.rules, indent=2, ensure_ascii=False)}
        
        ## 候选股票池（来自复盘报告）
        {json.dumps(stock_pool, indent=2, ensure_ascii=False)}
        
        ## 要求
        输出JSON:
        {{
            "actions": [
                {{
                    "symbol": "SH600519",
                    "action": "buy/sell/hold",
                    "quantity": 100,
                    "price": 1680.00,
                    "reason": "放量突破20日线，板块强度92",
                    "confidence": 0.85,
                    "stop_loss": 1620.00,
                    "take_profit": 1800.00
                }}
            ],
            "max_positions": 5,
            "total_capital_used": 0.6
        }}
        """
        
        result = await self.agent._run(prompt, self.agent._build_system_prompt())
        plan = json.loads(result)
        
        return plan
    
    async def _execute_morning(self, plan: dict) -> list[dict]:
        """上午盘执行交易"""
        
        trades = []
        actions = plan.get("actions", [])
        
        for action in actions:
            # 检查交易规则
            if not self._check_rules(action):
                logger.info(f"Rule check failed: {action['symbol']}")
                continue
            
            # 检查置信度
            if action.get("confidence", 0) < self.account.rules.get("min_confidence", 0.7):
                continue
            
            # 执行交易
            if action["action"] == "buy":
                trade = await self._buy(
                    symbol=action["symbol"],
                    price=action["price"],
                    quantity=action["quantity"],
                    reason=action.get("reason", ""),
                    confidence=action.get("confidence", 0.5),
                )
                if trade:
                    trades.append(trade)
            
            elif action["action"] == "sell":
                trade = await self._sell(
                    symbol=action["symbol"],
                    price=action["price"],
                    quantity=action["quantity"],
                    reason=action.get("reason", ""),
                )
                if trade:
                    trades.append(trade)
        
        return trades
    
    async def _execute_afternoon(self) -> list[dict]:
        """下午盘 - 主要是止损/止盈监控"""
        
        trades = []
        positions = await self.portfolio.get_positions()
        
        for pos in positions:
            current_price = await get_realtime_price(pos.symbol)
            pnl_pct = (current_price - pos.avg_cost) / pos.avg_cost
            
            # 止损检查
            stop_loss = self.account.rules.get("stop_loss", 0.05)
            if pnl_pct <= -stop_loss:
                trade = await self._sell(
                    symbol=pos.symbol,
                    price=current_price,
                    quantity=pos.quantity,
                    reason=f"触发止损 {pnl_pct:.2%}",
                    is_stop_loss=True,
                )
                if trade:
                    trades.append(trade)
            
            # 止盈检查
            take_profit = self.account.rules.get("take_profit", 0.15)
            if pnl_pct >= take_profit:
                trade = await self._sell(
                    symbol=pos.symbol,
                    price=current_price,
                    quantity=pos.quantity,
                    reason=f"触发止盈 {pnl_pct:.2%}",
                    is_take_profit=True,
                )
                if trade:
                    trades.append(trade)
        
        return trades
    
    async def _buy(self, symbol: str, price: float, quantity: int, 
                   reason: str, confidence: float = 0.5,
                   stop_loss: float = None, take_profit: float = None) -> dict:
        """执行买入"""
        
        # 检查资金
        amount = price * quantity
        fee = amount * 0.0003  # 手续费
        
        if amount + fee > self.account.current_capital:
            logger.warning(f"Insufficient funds: {symbol}")
            return None
        
        # 检查单票仓位限制
        max_pos = self.account.rules.get("max_position", 0.2)
        if amount > self.account.current_capital * max_pos:
            quantity = int(self.account.current_capital * max_pos / price / 100) * 100
            amount = price * quantity
            fee = amount * 0.0003
        
        # 更新持仓
        await self.portfolio.add_position(symbol, quantity, price)
        
        # 扣减资金
        self.account.current_capital -= (amount + fee)
        await self._update_account()
        
        # 记录交易
        trade = {
            "account_id": self.account_id,
            "symbol": symbol,
            "action": "buy",
            "quantity": quantity,
            "price": price,
            "amount": amount,
            "fee": fee,
            "reason": reason,
            "confidence": confidence,
        }
        await save_trade(self.db, trade)
        
        return trade
    
    async def _sell(self, symbol: str, price: float, quantity: int, 
                    reason: str, **kwargs) -> dict:
        """执行卖出"""
        
        # 检查持仓
        position = await self.portfolio.get_position(symbol)
        if not position or position.remaining_qty < quantity:
            logger.warning(f"Insufficient position: {symbol}")
            return None
        
        amount = price * quantity
        fee = amount * 0.0003
        
        # 计算盈亏
        pnl = (price - position.avg_cost) * quantity - fee
        
        # 更新持仓
        await self.portfolio.reduce_position(symbol, quantity)
        
        # 增加资金
        self.account.current_capital += (amount - fee)
        await self._update_account()
        
        # 记录交易
        trade = {
            "account_id": self.account_id,
            "symbol": symbol,
            "action
